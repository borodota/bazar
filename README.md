# 💨 VAPEBAZAR PREMIUM — Telegram Mini App & Bot

Экосистема для автоматизации продаж в г. Магадан: вейп-продукция (под-системы, жидкости, одноразки, расходники), техника под заказ из Дубая (iPhone, MacBook, Samsung, Apple Watch, консоли) и **VPN-подписки** (VLESS + Reality). Состоит из Telegram Mini App (витрина + корзина) и бэкенд-бота на Python (`aiogram 3`), который принимает заказы, продаёт VPN-доступ и шлёт уведомления администратору.

## 🖼️ Аватарки из Telegram — Настройка (обязательно!)

Аватарки в профиле работают через серверный relay (Edge Function). Без него GitHub Pages не может обратиться к Bot API напрямую — браузер блокирует.

### Шаг 1 — Деплой на Vercel (один раз, бесплатно)

1. Зайди на [vercel.com](https://vercel.com) → **Add New Project → Import Git Repository**
2. Выбери репозиторий `borodota/bazar`
3. В настройках проекта → **Settings → Environment Variables** — добавь:
   ```
   Name:  BOT_TOKEN
   Value: (токен твоего бота из @BotFather)
   ```
4. Нажми **Deploy**. Vercel выдаст URL вида `https://bazar-xxxxxx.vercel.app`

### Шаг 2 — Вписать URL в `script.js`

Открой `script.js`, найди строку (~50):
```js
const RELAY_URL = "";
```
Замени на:
```js
const RELAY_URL = "https://bazar-xxxxxx.vercel.app/api/relay";
```
(вставь свой реальный домен из Vercel)

После этого `git push` — аватарки появятся в течение 1–2 минут.

## 🚀 Бот на сервере (продакшен)

Бот развёрнут на VPS как systemd-сервис — работает круглосуточно, сам перезапускается при сбое.

```bash
# Обновить код и перезапустить бота
cd /opt/bazar
git pull
systemctl restart vapebazar-bot

# Проверить статус
systemctl status vapebazar-bot

# Смотреть логи в реальном времени
journalctl -u vapebazar-bot -f
```

Полная инструкция первичной установки (клонирование, перенос данных, systemd, ротация логов) — в [`deploy/SERVER_SETUP.md`](deploy/SERVER_SETUP.md).

### Локальный запуск (для разработки/тестов)

```bash
pip3 install -r requirements.txt   # Python 3.10+, aiogram 3.7+
python3 bott.py
```

> ⚠️ Локально и на сервере бот **не должен работать одновременно** — Telegram long-polling не допускает двух активных инстансов одного бота (будут конфликты).

## 🔥 Бот не работает? Чек-лист

1. **Бот запущен?** Напиши боту `/start`. Не отвечает → на сервере проверь `systemctl status vapebazar-bot`, локально — `ps aux | grep bott.py`.
2. **Логи.** `journalctl -u vapebazar-bot -n 50` (сервер) или `tail -f bot.log` (локально).
3. **Версия aiogram.** Нужна aiogram **3.7+** из `requirements.txt`.
4. **Токен/секреты.** На сервере лежат в `/etc/vapebazar-bot.env` (не в git).
5. **Заказы не приходят.** Админ должен **хотя бы раз написать боту** `/start` — иначе Telegram не даёт боту писать ему первым.
6. **`/orders` и `/top` пусты.** Заполняются после первого принятого заказа. Нажми «✅ Принять» под уведомлением о заказе.
7. **VPN не выдаётся.** Проверь, что панель 3x-ui запущена (`x-ui status`) и путь к базе в `.env` (`XUI_DB_PATH`) верный.

## 📱 Фичи Mini App

### 🏠 Навигация
Bottom tabs в стиле Instagram: **Каталог · Избранное · История · Профиль**. Активный таб светится неоном с анимацией появления.

### 👤 Профиль
- **Аватар из Telegram** с вращающимся неоновым кольцом (gradient)
- **Уровень лояльности** (Начинающий / Бронза / Серебро / Золото / Платина) меняет цвет кольца
- **Цветовые темы** — 5 акцентных цветов (зелёный / фиолетовый / розовый / синий / золотой), синхронизируются через Telegram CloudStorage
- **История заказов** с актуальными статусами

### 🎁 Hero-баннер
Большая карточка с промокодом и анимированным орбом. Тап открывает онбординг.

### 📦 Каталог и поиск
- **Skeleton-загрузка** — мерцающие заглушки вместо пустого экрана при загрузке
- **Фильтр по брендам** — чипы-кнопки прямо над каталогом
- Категории: Под-системы · Жидкости · Одноразки · Расходники · 🍏 Apple · 📱 Samsung · 🎮 Консоли · Другое
- **Debounced search** — фильтрация с задержкой 250 мс
- **Пагинация** — загружается по 20 карточек, остальные подгружаются при скролле (IntersectionObserver)
- **Кнопка «Вверх»** — появляется после прокрутки 400 px
- **Фильтры и сортировка** — по цене, скидки, в наличии, новинки
- **Badges** — `New`, `Хит`, `Скидка`, `🔥 N шт.`

### 🛒 Корзина и оформление
- Степпер количества, промокоды, комментарий к каждой позиции
- Прогресс-бар до бесплатной доставки (порог 2 000 ₽), минимальный заказ 500 ₽
- **Способ получения:** самовывоз или доставка с выбором временного слота
- **Способ оплаты:** наличка (с расчётом сдачи) или перевод
- Контактные данные автозаполняются из Telegram (имя, @username)
- Несколько сохранённых адресов доставки
- Корзина сохраняется между сессиями (localStorage)

### 🛡️ VPN-подписка
Отдельный раздел в профиле — быстрый VPN (VLESS + Reality, сервер в Нидерландах) прямо в магазине.

| Тариф | Срок | Цена |
|---|---|---|
| Пробный | 7 дней | 50 ₽ |
| Месяц | 30 дней | 150 ₽ |
| 3 месяца | 90 дней | 400 ₽ |
| Полгода | 180 дней | 700 ₽ |
| Год | 365 дней | 1 200 ₽ |

Оплата — напрямую директору. После подтверждения («✅ Оплачено — выдать») бот сам создаёт доступ в панели 3x-ui и присылает клиенту рабочую ссылку + инструкцию (приложение **HAPP**). Продление продлевает срок без потери оставшихся дней.

### 📦 Спецзаказ
Заявка на товар под заказ из Москвы/Дубая за 7–14 дней. Обязательная предоплата. Приходит админу с кнопкой «Связаться».

### 💎 Бонусная система
+5% баллами с каждого заказа, списать до 20% суммы. Баланс в Telegram CloudStorage (синхронизация между устройствами). Реферальная программа — приглашённый получает скидку, пригласивший получает баллы.

### UX детали
- Онбординг при первом запуске (промокод `НОВИЧОК10` −10%)
- Swipe-to-close на всех шторках, кнопка «Назад» Telegram интегрирована во все шторки
- Haptic feedback, fly-dot анимация при добавлении в корзину

## 🤖 Бот (`bott.py`)

### Типы сообщений из Mini App

| Тип | Когда | Кому уходит |
|---|---|---|
| Обычный заказ | «Оформить заказ» в корзине | Покупателю + админу с inline-кнопками статусов |
| `order_log` | Закрытие экрана успеха | Внутренний лог (`orders_log.json`) |
| `special_order` | Форма спецзаказа | Админу — `📦 СПЕЦЗАКАЗ ПОД ЗАКАЗ` |
| `vpn_order` | Покупка VPN-тарифа | Админу — заявка с кнопкой «✅ Оплачено — выдать» |
| `notify_request` | 🔔 у товара «нет в наличии» | Админу — `🔔 Запрос наличия` |
| `newsletter_subscribe` | Подписка в профиле | Админу — `📣 Новая подписка` |

### Управление статусами заказа
Inline-кнопки: *Принят → В сборке → Отправлен → Выполнен / Отменён*.
Клиент получает уведомление при каждой смене статуса, при выполнении — автоматически чек. Менять статус могут только админы.

### Выдача VPN
Кнопка «✅ Оплачено — выдать» под заявкой создаёт (или продлевает) клиента напрямую в базе панели 3x-ui и отправляет ему рабочую ссылку. Учёт подписок — `vpn_subs.json`.

### Автоответ вне рабочего времени
Если клиент пишет боту после 21:00 или до 9:00 по Магадану — бот отвечает, что магазин закрыт, и уведомляет менеджера.

### FAQ автоответы
Бот автоматически отвечает на популярные вопросы: оплата, доставка, сроки, гарантия, возврат, баллы, реферальная программа, режим работы.

### Команды администратора

| Команда | Что делает |
|---|---|
| `/stats` | Заказы и выручка за сегодня / 7 дней / всё время |
| `/orders` | Последние заказы с суммой и статусом |
| `/top` | Топ товаров по количеству продаж |
| `/export` | Выгрузить все заказы в CSV-файл (Excel) |
| `/vpn_subs` | Список активных VPN-подписок и сроков |
| `/broadcast <текст>` | Рассылка всем подписчикам (поддерживает HTML) |
| `/broadcast_buyers <текст>` | Рассылка только покупателям |
| `/bonus <ID>` | Показать баланс баллов клиента |
| `/restock <товар>` | Уведомить клиентов о поступлении товара |

### Команды клиента

| Команда | Что делает |
|---|---|
| `/birthday ДД.ММ` | Сохранить дату рождения — в этот день бот начислит +100 баллов |

```text
├── index.html          — разметка (шапка, табы, hero, шторки, профиль, VPN-магазин)

├── xui_db.py           — выдача VPN: прямая запись в базу панели 3x-ui

├── test_xui_api.py     — юнит-тесты legacy-модуля

├── api/
│   └── relay.js        — Vercel Edge Function (прокси к Bot API для аватарок)
├── deploy/
│   ├── SERVER_SETUP.md          — пошаговый перенос бота на VPS
│   ├── vapebazar-bot.service    — systemd-юнит (автозапуск, авторестарт)
│   ├── vapebazar-bot.logrotate  — ротация bot.log
│   └── env.example               — шаблон секретов (.env на сервере)
├── vercel.json          — конфиг Vercel
└── img/                 — изображения товаров
```

## ⚙️ Конфиги

### `bott.py`
| Константа | Значение |
|---|---|
| `BOT_TOKEN` (env) | Токен бота из @BotFather |
| `ADMIN_ID` | Главный админ |
| `DEPUTY_ADMIN_IDS` | Дополнительные админы |
| `DELIVERY_BASE_COST` | 250 ₽ |
| `FREE_DELIVERY_THRESHOLD` | 2 000 ₽ |
| `VPN_TARIFFS` | Тарифы VPN (см. таблицу выше) |
| `REFERRAL_REWARD` | 200 баллов за первый заказ друга |

### `script.js`
| Константа | Значение |
|---|---|
| `RELAY_URL` | URL задеплоенного Vercel relay (для аватарок) |
| `MIN_ORDER_AMOUNT` | 500 ₽ |
| `FREE_DELIVERY_THRESHOLD` | 2 000 ₽ |
| `VPN_TARIFFS` | Тарифы VPN — id/название/дни/цена |
| `PROMO_CODES` | `BORO`, `НОВИЧОК10` |

### `.env` на сервере (см. `deploy/env.example`)
| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен бота |
| `XUI_DB_PATH` | Путь к базе панели 3x-ui (`/etc/x-ui/x-ui.db`) |
| `XUI_SERVER_HOST` | IP сервера — подставляется в VPN-ссылку |
| `XUI_INBOUND_REMARK` | Имя инбаунда в панели (`MyVPN`) |
| `XUI_RESTART_CMD` | Команда перезагрузки Xray после выдачи (`systemctl restart x-ui`) |

### `api/relay.js` (Vercel Edge Function)
| Переменная | Где ставить |
|---|---|
| `BOT_TOKEN` | Vercel Dashboard → Settings → Environment Variables |
