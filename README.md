# 💨 VAPEBAZAR PREMIUM — Telegram Mini App & Bot

Экосистема для автоматизации продаж вейп-продукции (под-системы, жидкости, одноразки, расходники) в г. Магадан. Состоит из Telegram Mini App (витрина + корзина) и бэкенд-бота на Python (`aiogram 3`), который принимает заказы и шлёт уведомления администратору.

🌐 **Mini App:** https://borodota.github.io/bazar/
🤖 **Бот:** [@VapeBazar_bot](https://t.me/VapeBazar_bot)
📞 **Поддержка:** [@BORO_DOTA](https://t.me/BORO_DOTA)

---

## ⚠️ ВАЖНО

**Бот живёт пока работает компьютер где запущен `bott.py`.** Если выключить компьютер или закрыть процесс — бот замолчит, заказы перестанут приходить.

Для постоянной работы 24/7 либо переноси бот на VPS (~200₽/мес), либо настрой автозапуск через `launchd` (macOS).

## 🚀 Запуск бота

### Установка зависимостей (один раз)
```bash
cd ~/bazar/
pip3 install -r requirements.txt
```
Нужен Python 3.10+ и aiogram **3.7+** (ставится из `requirements.txt`).

### Первый запуск
```bash
cd ~/bazar/
python3 bott.py
```

### Запуск в фоне (можно закрыть терминал)
```bash
cd ~/bazar/
nohup python3 bott.py >> bot.log 2>&1 &
disown
```

### Проверить что бот работает
```bash
ps aux | grep bott.py | grep -v grep
tail -10 ~/bazar/bot.log
```
Должно быть: `Run polling for bot @VapeBazar_bot`.

### Остановить бот
```bash
pkill -9 -f bott.py
```

## 🔥 Бот не работает? Чек-лист

1. **Бот запущен?** Напиши боту `/start`. Не отвечает → процесс не работает, запусти `python3 bott.py` и смотри ошибки в консоли / `bot.log`.
2. **Версия aiogram.** Нужна aiogram **3.7+** и код из этого репозитория. Старый код с `Bot(token, parse_mode=...)` падает на новых версиях с ошибкой `TypeError: Passing parse_mode ... is not supported anymore`.
3. **Токен.** Если токен перевыпускался в @BotFather — обнови его (см. «Безопасность» ниже).
4. **Заказы не приходят админу.** Админ (ID из `ADMIN_ID` / `DEPUTY_ADMIN_IDS`) должен **хотя бы раз написать боту** `/start` — иначе Telegram не даёт боту писать ему первым. Ошибки отправки видны в `bot.log`.
5. **Магазин открывается, но заказ не уходит.** `tg.sendData()` работает только если Mini App открыт **через кнопку бота** («📱 Открыть Магазин / Корзину»), а не по прямой ссылке на сайт.

## 🔒 Безопасность токена

Токен бота указан в коде как запасной вариант и **виден всем в публичном репозитории**. Рекомендуется:

1. Перевыпустить токен в [@BotFather](https://t.me/BotFather) → `/revoke`.
2. Передавать новый токен через переменную окружения, не записывая его в код:

```bash
export BOT_TOKEN="ваш_новый_токен"
python3 bott.py
```

## 📱 Фичи Mini App

### 🏠 Bottom Tabs (Instagram-style навигация)
Четыре таба внизу: **Каталог · Избранное · История · Профиль**. Активный таб светится зелёным неоном.

### 🎁 Hero-баннер
Сверху каталога — большая карточка с промокодом `НОВИЧОК10` и анимированным "орбом". Тап открывает онбординг.

### 👤 Профиль
- Аватар из Telegram с **вращающимся неоновым кольцом** (gradient)
- Имя и `@username` подтягиваются автоматически
- Карточки: Спецзаказ, Реферальная программа, Поддержка, Рассылка

### 📦 Спецзаказ под заказ
Если товара нет в каталоге — клиент оставляет заявку. Привозим из Москвы за 7–14 дней.
**Обязательная предоплата** (полная или частичная) — без подтверждения чекбокса заявка не уходит.
Заявки приходят админу как `📦 СПЕЦЗАКАЗ ПОД ЗАКАЗ` с кнопкой "Связаться".

### Каталог и поиск
- Категории, поиск по имени и бренду, секция **🔥 Хиты продаж**
- **Фильтры и сортировка** — по цене ↑↓, скидки, в наличии, новинки
- **Badges** — `New`, `Хит`, `Скидка`, `🔥 N шт.` (осталось мало)
- **"Смотрят сейчас"** — счётчик живых просмотров
- **Lazy loading** изображений
- **3D Tilt** — карточки наклоняются в 3D при касании
- **CTA "Закажи под заказ"** при пустом результате поиска

### Карточка товара
- Выбор вкуса / цвета / испарителя
- **Секция "С этим берут"** — сопутствующие товары
- **Уведомление о наличии** — для товаров `inStock: false` кнопка вместо "В корзину"
- **Кнопка ❤️** — добавить в избранное прямо с карточки

### Корзина
- Степпер количества, промокоды (`BORO`, `НОВИЧОК10`)
- **Прогресс-бар** до бесплатной доставки (порог 2 000 ₽)
- **Индикатор минимального заказа** (500 ₽)
- Расчёт доставки 250 ₽ (самовывоз / курьер)
- **Корзина сохраняется** между сессиями (localStorage)

### UX
- **Онбординг** при первом запуске — промокод `НОВИЧОК10` (-10%)
- **Swipe-to-close** — все шторки закрываются свайпом вниз
- Haptic feedback, fly-dot анимация полёта в корзину
- Кнопка Назад Telegram интегрирована во все шторки
- **iOS-фиксы** — safe area, `-webkit-appearance: none`, dvh, swipe-fix

### Реферальная программа
- Уникальный промокод из Telegram ID
- Друг получает **5% скидку**, реферер — **5% на следующий заказ**
- Применяется автоматически при входе по реферальной ссылке

### Избранное
- Кнопка ♡ на каждой карточке, отдельный таб
- Сохраняется в localStorage

### Рассылка
- One-tap подписка на акции
- Данные отправляются боту через `sendData`

## 🤖 Бот (`bott.py`)

Принимает 4 типа сообщений из Mini App через `tg.sendData()`:

| Тип | Когда | Кому уходит |
|---|---|---|
| Обычный заказ (без `type`) | "Оформить заказ" в корзине | Покупателю в ЛС + админу с inline-кнопками статусов |
| `special_order` | Заявка из формы спецзаказа | Админу — `📦 СПЕЦЗАКАЗ ПОД ЗАКАЗ` |
| `notify_request` | Тап на 🔔 у товара "нет в наличии" | Админу — `🔔 Запрос наличия` |
| `newsletter_subscribe` | Подписка на рассылку в профиле | Админу — `📣 Новая подписка` |

### Управление статусами заказа
Inline-кнопки под заказом: *Принят → В сборке → Отправлен → Выполнен / Отменён*

- **Клиент получает уведомление при каждой смене статуса заказа**
- Менять статус могут только админы (проверка по ID)
- Заказы, отправленные пока бот был выключен, доставятся после его запуска

### 🛠 Команды администратора
Доступны только админам (`ADMIN_ID` / `DEPUTY_ADMIN_IDS`), у остальных не работают. Список показывается админу автоматически при `/start`.

| Команда | Что делает |
|---|---|
| `/stats` | Заказы и выручка за сегодня / 7 дней / всё время + число подписчиков |
| `/orders` | Последние 15 заказов с суммой и статусом |
| `/broadcast <текст>` | Рассылка всем, кто запускал бота (поддерживает HTML) |

### 📣 Рассылка
Бот запоминает **всех, кто хоть раз ему писал** (`subscribers.json`). Команда `/broadcast Завезли новинки 🔥` разошлёт текст всем разом и покажет, сколько доставлено / не доставлено.

### 🧾 Журнал заказов и 💎 бонусы
- Заказы складываются в `orders_log.json` — отсюда берутся `/orders` и `/stats`. Заказ попадает в журнал когда приходит через кнопку «Открыть Магазин» **или** когда вы жмёте любую кнопку статуса под ним.
- **Бонусные баллы** считаются в Mini App: +5% баллами с каждого заказа, списать можно до 30% суммы (1 балл = 1 ₽). Баланс хранится в Telegram CloudStorage и синхронизируется между устройствами клиента.

> `subscribers.json` и `orders_log.json` создаются автоматически при работе бота и **не** коммитятся в git (они в `.gitignore`) — это локальные данные конкретной установки.
