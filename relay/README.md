# 🔐 Релей для токена бота (Cloudflare Worker)

## Зачем это нужно

Сейчас токен бота лежит прямо в `script.js`. Этот файл раздаётся **публично**
через GitHub Pages — значит, токен может забрать кто угодно. С токеном чужой
человек может писать твоим клиентам от имени магазина, читать переписку и менять
настройки бота. Это опасно.

**Решение:** маленький бесплатный сервер (Cloudflare Worker) держит токен у себя,
а сайт магазина общается с ним, а не с Telegram напрямую. Токен наружу больше не
виден. Воркер ещё и проверяет подпись Telegram, поэтому слать спам через твой бот
тоже нельзя.

Это бесплатно (до 100 000 запросов в день — нам хватит с огромным запасом).

---

## Шаги (≈ 5 минут)

### 1. Создай аккаунт Cloudflare
Зайди на https://dash.cloudflare.com/sign-up — обычная почта + пароль, карта не нужна.

### 2. Создай воркер
1. В панели слева открой **Workers & Pages** → кнопка **Create application** → **Create Worker**.
2. Имя придумай, например `vapebazar-relay`. Жми **Deploy** (пока с заглушкой).
3. После деплоя жми **Edit code**.
4. Удали весь код, который там есть, и вставь содержимое файла
   [`relay/worker.js`](./worker.js) из этого репозитория.
5. Жми **Deploy** (справа сверху).

### 3. Положи токен в секрет (он будет скрыт)
1. Вернись на страницу воркера → вкладка **Settings** → раздел **Variables and Secrets**.
2. **Add** → тип **Secret** → имя переменной строго `BOT_TOKEN`, значение — токен бота.
3. Сохрани (**Deploy**, если попросит).

> ⚠️ Имя должно быть именно `BOT_TOKEN` — так его читает воркер.

### 4. Скопируй адрес воркера
На странице воркера будет ссылка вида:
```
https://vapebazar-relay.ТВОЁ-ИМЯ.workers.dev
```
Скопируй её и **пришли мне** — я подставлю её в `script.js` и удалю токен из кода.

---

## 5. Сменить токен (важно!)

Старый токен уже какое-то время был открыт, так что после запуска релея его лучше
**отозвать и получить новый**:

1. В Telegram открой **@BotFather** → `/mybots` → выбери бота → **API Token** → **Revoke current token**.
2. BotFather выдаст **новый токен**.
3. Новый токен нужно вписать в ДВА места:
   - **Cloudflare** → секрет `BOT_TOKEN` (заменить значение на новый);
   - **бот на Маке** → переменная окружения `BOT_TOKEN` для `bott.py`
     (или там, где сейчас задаётся токен), затем перезапустить бота.
4. В `script.js` токена уже не будет — там останется только адрес релея.

После этого старый токен (даже если он сохранился в истории git) станет
бесполезен. Дыра закрыта. ✅

---

## Как проверить, что работает

После того как я подставлю `RELAY_URL`, оформи тестовый заказ через бота —
уведомление должно прийти админам и подтверждение тебе, как раньше.
Если что-то не так — в консоли браузера (Telegram → меню → DevTools) будет
текст ошибки от релея.
