# 💨 VAPEBAZAR PREMIUM — Telegram Mini App & Bot

Экосистема для автоматизации продаж вейп-продукции (под-системы, жидкости, одноразки, расходники) в г. Магадан. Состоит из Telegram Mini App (витрина + корзина) и бэкенд-бота на Python (`aiogram 3`), который принимает заказы и шлёт уведомления администратору.

## 🖼️ Аватарки из Telegram — Настройка (обязательно!)

Аватарки в профиле работают через серверный relay (Edge Function). Без него GitHub Pages не может обратиться к Bot API напрямую — браузер блокирует.

### Шаг 1 — Деплой на Vercel (один раз, бесплатно)

1. Зайди на [vercel.com](https://vercel.com) → **Add New Project → Import Git Repository**
2. Выбери репозиторий `borodota/bazar`
3. В настройках проекта → **Settings → Environment Variables** — добавь:
   ```
   Name:  BOT_TOKEN
   Value: (токен твоего бота из @BotFather)
   ```
4. Нажми **Deploy**. Vercel выдаст URL вида `https://bazar-xxxxxx.vercel.app`

### Шаг 2 — Вписать URL в `script.js`

Открой `script.js`, найди строку (~50):
```js
const RELAY_URL = "";
```
Замени на:
```js
const RELAY_URL = "https://bazar-xxxxxx.vercel.app/api/relay";
```
(вставь свой реальный домен из Vercel)

После этого `git push` — аватарки появятся в течение 1–2 минут.

**Бот живёт пока работает компьютер где запущен `bott.py`.** Если выключить компьютер или закрыть процесс — бот замолчит, заказы перестанут приходить.

Для постоянной работы 24/7 либо переноси бот на VPS (~200₽/мес), либо настрой автозапуск через `systemd` (Linux).

## 🚀 Запуск бота

### Установка зависимостей (один раз)
```bash
pip3 install -r requirements.txt
```
Нужен Python 3.10+ и aiogram **3.7+**.

### Запуск
```bash
python3 bott.py
```

### Запуск в фоне (можно закрыть терминал)
```bash
nohup python3 bott.py >> bot.log 2>&1 &
disown
```

### Проверить что бот работает
```bash
ps aux | grep bott.py | grep -v grep
tail -10 bot.log
```
Должно быть: `Run polling for bot @VapeBazar_bot`.

### Остановить бот
```bash
pkill -9 -f bott.py
```

### Обновить бот (git pull + перезапуск)
```bash
git pull
pkill -f bott.py
nohup python3 bott.py >> bot.log 2>&1 &
disown
```

## 🔥 Бот не работает? Чек-лист

1. **Бот запущен?** Напиши боту `/start`. Не отвечает → запусти `python3 bott.py` и смотри ошибки.
2. **Версия aiogram.** Нужна aiogram **3.7+** из `requirements.txt`.
3. **Токен.** Если перевыпускался в @BotFather — обнови его в `bott.py`.
4. **Заказы не приходят.** Админ должен **хотя бы раз написать боту** `/start` — иначе Telegram не даёт боту писать ему первым.
5. **`/orders` и `/top` пусты.** Команды заполняются после первого принятого заказа. Нажми «✅ Принять» под уведомлением о заказе, чтобы он попал в журнал.

## 📱 Фичи Mini App

### 🏠 Навигация
Bottom tabs в стиле Instagram: **Каталог · Избранное · История · Профиль**. Активный таб светится неоном с анимацией появления.

### 👤 Профиль
- **Аватар из Telegram** с вращающимся неоновым кольцом (gradient)
- **Уровень лояльности** (Начинающий / Бронза / Серебро / Золото / Платина) меняет цвет кольца
- **Цветовые темы** — 5 акцентных цветов (зелёный / фиолетовый / розовый / синий / золотой), синхронизируются через Telegram CloudStorage
- **История заказов** с актуальными статусами

### 🎁 Hero-баннер
Большая карточка с промокодом и анимированным орбом. Тап открывает онбординг.

### 📦 Каталог и поиск
- **Skeleton-загрузка** — мерцающие заглушки вместо пустого экрана при загрузке
- **Фильтр по брендам** — чипы-кнопки прямо над каталогом
- Категории, поиск по имени и бренду
- **Debounced search** — фильтрация с задержкой 250 мс
- **Пагинация** — загружается по 20 карточек, остальные подгружаются при скролле (IntersectionObserver)
- **Кнопка «Вверх»** — появляется после прокрутки 400 px
- Категорийные emoji-плейсхолдеры с акцент-цветами
- **Фильтры и сортировка** — по цене, скидки, в наличии, новинки
- **Badges** — `New`, `Хит`, `Скидка`, `🔥 N шт.`

### 🛒 Корзина
- Степпер количества, промокоды (`BORO`, `НОВИЧОК10`)
- **Комментарий к каждой позиции** — отдельное поле под товаром
- Прогресс-бар до бесплатной доставки (порог 2 000 ₽)
- Минимальный заказ 500 ₽
- Сохраняется между сессиями (localStorage)

### 📍 Оформление заказа
- **Несколько сохранённых адресов** — выбери из сохранённых или введи новый
- **Временные слоты доставки** — выбор удобного времени (9–12, 12–15, 15–18, 18–21, после 21)

### 📦 Спецзаказ
Заявка на товар под заказ из Москвы за 7–14 дней. Обязательная предоплата. Приходит админу с кнопкой "Связаться".

### 💎 Бонусная система
+5% баллами с каждого заказа, списать до 30% суммы. Баланс в Telegram CloudStorage (синхронизация между устройствами).

### UX детали
- Онбординг при первом запуске (промокод `НОВИЧОК10` −10%)
- Swipe-to-close на всех шторках
- Haptic feedback, fly-dot анимация при добавлении в корзину
- RAF-таймер в hero-баннере
- Кнопка Назад Telegram интегрирована во все шторки

## 🤖 Бот (`bott.py`)

### Типы сообщений из Mini App

| Тип | Когда | Кому уходит |
|---|---|---|
| Обычный заказ | «Оформить заказ» в корзине | Покупателю + админу с inline-кнопками статусов |
| `order_log` | Закрытие экрана успеха | Внутренний лог (логирует в `orders_log.json`) |
| `special_order` | Форма спецзаказа | Админу — `📦 СПЕЦЗАКАЗ ПОД ЗАКАЗ` |
| `notify_request` | 🔔 у товара «нет в наличии» | Админу — `🔔 Запрос наличия` |
| `newsletter_subscribe` | Подписка в профиле | Админу — `📣 Новая подписка` |

### Управление статусами
Inline-кнопки: *Принят → В сборке → Отправлен → Выполнен / Отменён*
Клиент получает уведомление при каждой смене статуса. При выполнении заказа — автоматически отправляется чек. Менять могут только админы.

### Автоответ вне рабочего времени
Если клиент пишет боту после 21:00 или до 9:00 по Магадану — бот отвечает, что магазин закрыт, и уведомляет менеджера.

### FAQ автоответы
Бот автоматически отвечает на популярные вопросы: оплата, доставка, сроки, гарантия, возврат, баллы, реферальная программа, режим работы.

### Команды администратора

| Команда | Что делает |
|---|---|
| `/stats` | Заказы и выручка за сегодня / 7 дней / всё время |
| `/orders` | Последние 15 заказов с суммой и статусом |
| `/top` | Топ-10 товаров по количеству продаж |
| `/export` | Выгрузить все заказы в CSV-файл (Excel) |
| `/broadcast <текст>` | Рассылка всем подписчикам (поддерживает HTML) |
| `/broadcast_buyers <текст>` | Рассылка только покупателям |
| `/bonus <ID>` | Показать баланс баллов клиента |
| `/restock <товар>` | Уведомить клиентов о поступлении товара |

## ⚙️ Конфиги

### `bott.py`
| Константа | Значение |
|---|---|
| `BOT_TOKEN` (env) | Токен бота из @BotFather |
| `ADMIN_ID` | Главный админ |
| `DEPUTY_ADMIN_IDS` | Дополнительные админы |
| `DELIVERY_BASE_COST` | 250 ₽ |
| `FREE_DELIVERY_THRESHOLD` | 2 000 ₽ |
| `SHOP_OPEN_HOUR` | 9 (час открытия по Магадану) |
| `SHOP_CLOSE_HOUR` | 21 (час закрытия по Магадану) |

### `script.js`
| Константа | Значение |
|---|---|
| `RELAY_URL` | URL задеплоенного Vercel relay (для аватарок) |
| `MIN_ORDER_AMOUNT` | 500 ₽ |
| `DELIVERY_COST` | 250 ₽ |
| `FREE_DELIVERY_THRESHOLD` | 2 000 ₽ |
| `PROMO_CODES` | `BORO`, `НОВИЧОК10` |

### `api/relay.js` (Vercel Edge Function)
| Переменная | Где ставить |
|---|---|
| `BOT_TOKEN` | Vercel Dashboard → Settings → Environment Variables |
