# 💨 VAPEBAZAR PREMIUM — Telegram Mini App & Bot

Экосистема для автоматизации продаж вейп-продукции (под-системы, жидкости, одноразки, расходники) в г. Магадан. Состоит из Telegram Mini App (витрина + корзина) и бэкенд-бота на Python (`aiogram 3`), который принимает заказы и шлёт уведомления администратору.

---

## 🚀 Быстрый старт (запуск бота)

### 1. Требования
- Python 3.10+
- Библиотеки из `requirements.txt` (aiogram 3.7+)

### 2. Установка

```bash
git clone https://github.com/borodota/bazar.git
cd bazar
pip install -r requirements.txt
```

### 3. Запуск

```bash
python bott.py
```

В консоли появится `Запуск сервера бота VAPEBAZAR PREMIUM...` — бот работает. Все события пишутся в файл `bot.log`.

> ⚠️ **Важно:** бот должен быть запущен **постоянно** (24/7). Если процесс остановлен — клиенты не смогут открыть магазин через кнопку, а заказы не будут приходить. Запускайте бота на VPS/сервере, а не на личном компьютере.

### 4. Запуск 24/7 на сервере (systemd)

Создайте файл `/etc/systemd/system/vapebazar.service`:

```ini
[Unit]
Description=VAPEBAZAR Telegram Bot
After=network.target

[Service]
WorkingDirectory=/путь/до/bazar
ExecStart=/usr/bin/python3 bott.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now vapebazar
sudo systemctl status vapebazar   # проверить, что работает
```

`Restart=always` автоматически перезапустит бота, если он упадёт.

## 🔥 Бот не работает? Чек-лист

1. **Бот запущен?** Напишите боту `/start`. Не отвечает → процесс не работает, запустите `python bott.py` и смотрите ошибки в консоли / `bot.log`.
2. **Версия aiogram.** Нужна aiogram **3.7+** и код из этого репозитория. Старый код с `Bot(token, parse_mode=...)` падает на новых версиях с ошибкой `TypeError: Passing parse_mode ... is not supported anymore`.
3. **Токен.** Если токен перевыпускался в @BotFather — обновите его (см. «Безопасность» ниже).
4. **Заказы не приходят админу.** Админ (ID из `ADMIN_ID` / `DEPUTY_ADMIN_IDS`) должен **хотя бы раз написать боту** `/start` — иначе Telegram не даёт боту писать ему первым. Ошибки отправки видны в `bot.log`.
5. **Магазин открывается, но заказ не уходит.** `tg.sendData()` работает только если Mini App открыт **через кнопку бота** («📱 Открыть Магазин / Корзину»), а не по прямой ссылке на сайт.

## 🔒 Безопасность токена

Токен бота сейчас указан в коде как запасной вариант, и он **виден всем в публичном репозитории**. Рекомендуется:

1. Перевыпустить токен в [@BotFather](https://t.me/BotFather) → `/revoke`.
2. Передавать новый токен через переменную окружения, не записывая его в код:

```bash
export BOT_TOKEN="ваш_новый_токен"
python bott.py
```

Для systemd добавьте в секцию `[Service]`: `Environment=BOT_TOKEN=ваш_новый_токен`.

## 🤖 Что умеет бот

- Принимает заказы из Mini App через `tg.sendData()` (устойчив к JSON и обычному тексту)
- Мгновенно уведомляет администратора и заместителей (`ADMIN_ID`, `DEPUTY_ADMIN_IDS`)
- Управление статусами кнопками: *Принят → В сборке → Отправлен → Выполнен / Отменён*
- **Клиент получает уведомление при каждой смене статуса заказа**
- Менять статус могут только админы (проверка по ID)
- Спецзаказы под предоплату (`special_order`), запросы наличия (`notify_request`), подписки на рассылку (`newsletter_subscribe`)
- Заказы, отправленные пока бот был выключен, доставятся после его запуска

## 📱 Фичи Mini App

- **Каталог:** категории, поиск, фильтры и сортировка, бейджи `New` / `Хит` / `Скидка`, lazy loading
- **Карточка товара:** выбор вкуса/цвета, «С этим берут», уведомление о наличии, избранное
- **Корзина:** промокоды, прогресс-бар до бесплатной доставки, минимальный заказ, сохранение между сессиями
- **UX:** онбординг с промокодом, персональное приветствие, swipe-to-close, haptic feedback
- **Реферальная программа:** персональный код из Telegram ID, 5% другу и 5% рефереру
- **История заказов** (до 30) и **избранное** — локально в Mini App
- **Рассылка:** one-tap подписка на акции
