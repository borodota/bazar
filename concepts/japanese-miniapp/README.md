# VapeBazar — самостоятельный японский макет

Откройте `index.html` в браузере. Сборка, установка библиотек, токены и сервер не нужны. Все ресурсы находятся в этой папке; её можно скопировать отдельно.

Разделы: главная, каталог, выбор VPN, профиль, заказы, мой VPN, избранное, бонусы, настройки, инструкция, поддержка. Работают переходы, поиск, фильтры, избранное в памяти страницы, выбор срока и устройств, модальные карточки, светлая тема. Изображения категорий — иллюстрации, не фотографии конкретных моделей. Финансовые условия не заданы.

Это автономная демонстрация: нет Telegram SDK, запросов к API, оплаты, отправки заказов, реальных аккаунтов, подписок или уведомлений. Вейп-раздел обозначен только информационными названиями без продажи.

Основной проект, бот и конфигурация размещения не меняются. Не объединять с main и не развёртывать вместо действующего магазина без отдельного решения. Подключённые к репозиторию внешние сервисы могут автоматически собирать ветки — их настройки этот макет не меняет.
