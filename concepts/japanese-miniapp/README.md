# VapeBazar · Японская ночь

Самостоятельный интерактивный концепт на HTML, CSS и JavaScript. Все зависимости находятся внутри этой папки; можно открыть `index.html` без сборки.

## Экраны и действия

- Главная, каталог, страница товара, VPN, профиль, заказы, мой VPN, избранное, бонусы, настройки, инструкция и поддержка.
- Поиск без потери фокуса, категории, фильтр избранного и сортировка по названию.
- Избранное и настройки оформления сохраняются в отдельном ключе localStorage `vb-japan-concept-v2`. При недоступном хранилище приложение работает в памяти.
- Варианты товара, миниатюры и параметры VPN переключаются без перерисовки всей страницы.
- Диалог показывает выбранные параметры; заказ, платёж или сообщение не отправляются.
- «Назад» и нижняя навигация используют hash-маршруты, позиции прокрутки сохраняются в рамках сеанса.
- Настройки: тёмная/светлая/системная тема, уменьшение анимации.
- В настройках есть «Просмотр UX-состояний»: загрузка, пустая выдача и ошибка сети. Это явные демонстрации, а не настоящие запросы.
- Прямые маршруты: `#home`, `#catalog`, `#product/phone`, `#vpn`, `#profile`, `#orders`, `#myvpn`, `#favorites`, `#bonus`, `#settings`, `#guide`, `#support`, `#loading`, `#empty`, `#error`.

## Данные и ограничения

Нет запросов к API магазина, Telegram SDK, платежей, выдачи VPN и реальных аккаунтов. Это не готовая интеграция с ботом. Поддержка содержит 8 ответов на частые вопросы, выбор темы и редактор черновика с копированием. Черновики хранятся только в памяти страницы, отдельно для каждой темы; сообщения никуда не отправляются. При недоступном Clipboard API текст выделяется для ручного копирования. Правила бонусов, VPN-клиент, стоимость и параметры настоящих моделей не выдуманы.

На карточках — существующие иллюстрации категорий из проекта, не фотографии выбранных моделей. Изображение `accessories.webp` скопировано из существующего `img/card-accessories.webp`; оригинал не меняется. Обложка техники используется для смартфонов и ноутбуков с соответствующей подписью. Знак VB пока выполнен типографикой, не является точной копией кистевого логотипа из концепт-изображений.

Никотиновые категории сохранены только информационными названиями без товарных предложений, цен или заказа.

Учтены CSS safe areas, экранная клавиатура через visualViewport, клавиатурный фокус, стандартный dialog, уменьшение движения и узкие экраны. Нативные панели Telegram и реальные устройства нужно проверить отдельно. Нарисованные в презентации рамки телефонов и системные панели не добавлены в веб-интерфейс.

## Изоляция и публикация

Изменения ограничены `concepts/japanese-miniapp/` в отдельной ветке. Основной магазин, бот, API и настройки публикации не изменены. Не объединять ветку с main и не назначать её production-веткой без отдельного согласования. Подключённый Vercel может автоматически создать предпросмотр ветки.

## Проверка

В текущей сессии локальная среда недоступна. Выполняются статические проверки и проверка JavaScript в изолированной среде с минимальным DOM-моком; это не браузерное тестирование. Перед объединением проверить на телефоне: все маршруты, поиск, фильтры, избранное, диалог/назад, VPN-выбор, 320 px и увеличение текста 200%, экранную клавиатуру и светлую тему.

## FAQ и анимации

Нативные details раскрываются и закрываются плавно через Web Animations API. Повторное нажатие меняет направление, при отсутствии API остаётся мгновенное раскрытие. Включены короткие появления экранов и содержимого диалогов, реакции кнопок и карточек. Системное уменьшение движения и переключатель в настройках отключают движение, в том числе завершают уже запущенные анимации. Для работы не добавлены зависимости или сетевые запросы.
