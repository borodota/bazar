# 💨 VAPEBAZAR PREMIUM — Telegram Mini App & Bot

Современная экосистема для автоматизации продаж вейп-продукции (под-системы, жидкости, одноразки, расходники) в г. Магадан. Состоит из Telegram Mini App и бэкенд-бота на Python (`aiogram 3`).

---

## 🚀 Фичи Mini App

### Каталог и поиск
- Категории, поиск по имени и бренду, секция **🔥 Хиты продаж**
- **Фильтры и сортировка** — по цене ↑↓, скидки, в наличии, новинки
- **Badges** — `New`, `Хит`, `Скидка`, `🔥 N шт.` (осталось мало)
- **"Смотрят сейчас"** — счётчик живых просмотров на популярных товарах
- **Lazy loading** изображений

### Карточка товара
- Выбор вкуса / цвета / испарителя прямо в шторке
- **Секция "С этим берут"** — сопутствующие расходники и жидкости
- **Уведомление о наличии** — для товаров `inStock: false` кнопка вместо "В корзину"
- **Кнопка ❤️** — добавить в избранное прямо с карточки

### Корзина
- Степпер количества, промокоды (`BORO`, `НОВИЧОК10`)
- **Прогресс-бар** до бесплатной доставки (порог 2 000 ₽)
- **Индикатор минимального заказа** (500 ₽)
- **Реферальная карточка** и **карточка поддержки** внутри корзины
- Расчёт доставки 250 ₽ (самовывоз / курьер)
- **Корзина сохраняется** между сессиями (localStorage)

### Пользовательский опыт
- **Онбординг** при первом запуске — промокод `НОВИЧОК10` (-10%)
- **Персональное приветствие** — `Привет, Иван 👋` из данных Telegram
- **Swipe-to-close** — все шторки закрываются свайпом вниз
- Haptic feedback, анимация полёта в корзину, toast-уведомления
- Кнопка Назад Telegram интегрирована во все шторки

### Реферальная программа
- Уникальный промокод для каждого пользователя (генерируется из Telegram ID)
- Ссылка для шаринга открывает `tg.openTelegramLink` с текстом
- Друг получает **5% скидку**, реферер — **5% на следующий заказ**
- Скидка применяется автоматически при входе по реферальной ссылке

### История заказов
- Все оформленные заказы сохраняются локально (до 30 штук)
- Экран истории прямо в Mini App — не нужно скроллить чат бота

### Избранное
- Кнопка ♡ на каждой карточке
- Отдельная шторка с быстрым переходом к товару
- Сохраняется в localStorage

### Рассылка
- One-tap подписка на акции и новинки
- Данные отправляются боту через `sendData`
- Баннер показывается только неподписанным (localStorage)

### Поддержка
- Кнопка "Написать в поддержку" в корзине → [`@BORO_DOTA`](https://t.me/BORO_DOTA)

## 🤖 Бэкенд-бот

- Принимает заказы из WebApp через `tg.sendData()`
- Устойчив к любым форматам (JSON / текст)
- Мгновенное уведомление `@BORO_DOTA` и менеджеров
- Управление статусами: *Принят → В сборке → Отправлен → Выполнен / Отменён*
- Обрабатывает запросы уведомлений о наличии (`notify_request`)
- Сохраняет данные подписчиков рассылки (`newsletter_subscribe`)

## 🛠️ Структура проекта

```text
├── index.html      — разметка Mini App (шапка, сетка, шторки, онбординг)
├── script.js       — вся логика: корзина, фильтры, рефералы, история, wishlist
├── products.js     — база товаров (id, цена, категория, вкусы, lowStock, viewers)
├── style.css       — UI: тёмная тема, неон, карточки, анимации, все компоненты
├── bott.py         — Telegram-бот (aiogram 3)
└── img/            — изображения товаров
```
