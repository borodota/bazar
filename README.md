## ⚠️ ВАЖНО

**Бот живёт пока работает компьютер где запущен `bott.py`.** Если выключить компьютер или закрыть процесс — бот замолчит, заказы перестанут приходить.

Для постоянной работы 24/7 либо переноси бот на VPS (~200₽/мес), либо настрой автозапуск через `launchd` (macOS).

## 🚀 Запуск бота

### Первый запуск
```bash
cd ~/bazar/
python3 bott.py
```

### Запуск в фоне (можно закрыть терминал)
```bash
cd ~/bazar/
nohup python3 bott.py >> bot.log 2>&1 &
disown
```

### Проверить что бот работает
```bash
ps aux | grep bott.py | grep -v grep
tail -10 ~/bazar/bot.log
```
Должно быть: `Run polling for bot @VapeBazar_bot`.

### Остановить бот
```bash
pkill -9 -f bott.py
```

## 🚀 Фичи Mini App

### 🏠 Bottom Tabs (Instagram-style навигация)
Четыре таба внизу: **Каталог · Избранное · История · Профиль**. Активный таб светится зелёным неоном.

### 🎁 Hero-баннер
Сверху каталога — большая карточка с промокодом `НОВИЧОК10` и анимированным "орбом". Тап открывает онбординг.

### 👤 Профиль
- Аватар из Telegram с **вращающимся неоновым кольцом** (gradient)
- Имя и `@username` подтягиваются автоматически
- Карточки: Спецзаказ, Реферальная программа, Поддержка, Рассылка

### 📦 Спецзаказ под заказ
Если товара нет в каталоге — клиент оставляет заявку. Привозим из Москвы за 7–14 дней.
**Обязательная предоплата** (полная или частичная) — без подтверждения чекбокса заявка не уходит.
Заявки приходят админу как `📦 СПЕЦЗАКАЗ ПОД ЗАКАЗ` с кнопкой "Связаться".

### Каталог и поиск
- Категории, поиск по имени и бренду, секция **🔥 Хиты продаж**
- **Фильтры и сортировка** — по цене ↑↓, скидки, в наличии, новинки
- **Badges** — `New`, `Хит`, `Скидка`, `🔥 N шт.` (осталось мало)
- **"Смотрят сейчас"** — счётчик живых просмотров
- **Lazy loading** изображений
- **3D Tilt** — карточки наклоняются в 3D при касании
- **CTA "Закажи под заказ"** при пустом результате поиска

### Карточка товара
- Выбор вкуса / цвета / испарителя
- **Секция "С этим берут"** — сопутствующие товары
- **Уведомление о наличии** — для товаров `inStock: false` кнопка вместо "В корзину"
- **Кнопка ❤️** — добавить в избранное прямо с карточки

### Корзина
- Степпер количества, промокоды (`BORO`, `НОВИЧОК10`)
- **Прогресс-бар** до бесплатной доставки (порог 2 000 ₽)
- **Индикатор минимального заказа** (500 ₽)
- Расчёт доставки 250 ₽ (самовывоз / курьер)
- **Корзина сохраняется** между сессиями (localStorage)

### UX
- **Онбординг** при первом запуске — промокод `НОВИЧОК10` (-10%)
- **Swipe-to-close** — все шторки закрываются свайпом вниз
- Haptic feedback, fly-dot анимация полёта в корзину
- Кнопка Назад Telegram интегрирована во все шторки
- **iOS-фиксы** — safe area, `-webkit-appearance: none`, dvh, swipe-fix

### Реферальная программа
- Уникальный промокод из Telegram ID
- Друг получает **5% скидку**, реферер — **5% на следующий заказ**
- Применяется автоматически при входе по реферальной ссылке

### Избранное
- Кнопка ♡ на каждой карточке, отдельный таб
- Сохраняется в localStorage

### Рассылка
- One-tap подписка на акции
- Данные отправляются боту через `sendData`

## 🤖 Бот (`bott.py`)

Принимает 4 типа сообщений из Mini App через `tg.sendData()`:

| Тип | Когда | Кому уходит |
|---|---|---|
| Обычный заказ (без `type`) | "Оформить заказ" в корзине | Покупателю в ЛС + админу с inline-кнопками статусов |
| `special_order` | Заявка из формы спецзаказа | Админу — `📦 СПЕЦЗАКАЗ ПОД ЗАКАЗ` |
| `notify_request` | Тап на 🔔 у товара "нет в наличии" | Админу — `🔔 Запрос наличия` |
| `newsletter_subscribe` | Подписка на рассылку в профиле | Админу — `📣 Новая подписка` |

### Управление статусами заказа
Inline-кнопки под заказом: *Принят → В сборке → Отправлен → Выполнен / Отменён*

```text

```
